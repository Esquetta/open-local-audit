# v0.2.0 Release Notes

## Highlights

- Adds optional same-origin internal link scanning with `--check-links`.
- Adds `--max-pages <count>` to bound link checks.
- Adds a `broken-internal-links` finding when same-origin links return 4xx, 5xx, or cannot be fetched.
- Adds `--fail-on none|high|medium|low` for CI and automation workflows.
- Adds compact terminal summaries when reports are written with `--out` or `--out-dir`.
- Adds integration coverage for local HTTP link scanning and CLI behavior helpers.

## Verification

Before tagging and publishing:

```bash
npm run release-check
npm pack
npx --yes --package ./open-local-audit-0.2.0.tgz open-local-audit --help
```

After npm publish:

```bash
npm view open-local-audit@0.2.0 version dist.tarball bin
npx --yes open-local-audit@0.2.0 --help
```

## Known limits

- Link scanning currently checks same-origin links discovered on the audited page; it does not crawl recursively.
- Browser-rendered DOM checks are not implemented yet.
- Screenshot capture and HTML reports are still deferred.
