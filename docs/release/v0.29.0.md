# Open Local Audit v0.29.0

Release date: 2026-06-08

## Summary

`v0.29.0` adds a separate automation summary JSON output for local shortlist runs. Operators can keep Markdown, JSON, or CSV shortlist reports for review while writing a compact machine-readable summary for local workflows.

## Changes

- Added `shortlist --summary-json <path>`.
- Added `renderShortlistSummaryJson` for package consumers.
- Summary JSON includes row counts plus selected lead rank, company, website, scores, and review status.
- Kept summary output separate from the main shortlist report format.

## Example

```bash
open-local-audit shortlist --input leads.csv --out shortlist.md --summary-json shortlist-summary.json
```

## Verification

```bash
npm run release-check
npm pack
npx --yes --package ./open-local-audit-0.29.0.tgz open-local-audit shortlist --help
```

## Known limits

- Summary JSON is a local automation aid only.
- Summary output does not mutate source files, mutate review CSV files, call APIs, send outreach, or sync CRM records.
