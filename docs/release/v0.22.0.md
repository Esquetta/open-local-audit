# Open Local Audit v0.22.0

Release date: 2026-05-31

## Summary

`v0.22.0` adds local lead shortlist reports for discovery and CRM CSV exports. Operators can rank leads into a focused Markdown or JSON review file before manual outreach decisions.

## Changes

- Added `shortlist --input <path> --out <path>`.
- Added Markdown shortlist output by default.
- Added JSON shortlist output with `--format json`.
- Ranked leads by opportunity score, priority, contact confidence, audit score, and company name.
- Supported common discovery CSV and CRM CSV column names.

## Example

```bash
open-local-audit shortlist --input leads.csv --out shortlist.md --top 20
open-local-audit shortlist --input crm-leads.csv --out shortlist.json --format json
```

## Verification

Run before publishing:

```bash
npm run release-check
npm pack
npx --yes --package ./open-local-audit-0.22.0.tgz open-local-audit --help
```

## Known limits

- Shortlist generation reads local CSV files only.
- Shortlist ranking is deterministic operator guidance, not a CRM score.
- Shortlist generation does not call APIs, send outreach, or sync CRM records.
