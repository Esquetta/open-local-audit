# v0.4.0 Release Notes

## Highlights

- Adds resilient batch execution: one failed URL no longer aborts the whole batch.
- Adds top-level batch index reports in JSON, Markdown, and HTML.
- Adds CSV batch input with `url`, `label`, and `segment` columns while keeping plain-text URL lists.
- Improves JSON-LD detection for common `@graph` structured-data shapes.
- Adds local-business quality checks for schema contact fields, Organization schema, visible address, opening hours, service-location copy, primary CTA, and placeholder copy.

## Verification

Before tagging and publishing:

```bash
npm run release-check
npm pack
npx --yes --package ./open-local-audit-0.4.0.tgz open-local-audit --help
```

After npm publish:

```bash
npm view open-local-audit@0.4.0 version dist.tarball bin
npx --yes open-local-audit --help
```

## Known limits

- Batch mode still runs sequentially.
- CSV support is intentionally minimal and supports named `url`, `label`, and `segment` columns.
- Browser-rendered DOM checks and screenshots are still deferred.
