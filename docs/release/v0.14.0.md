# v0.14.0 Release Notes

## Highlights

- Added `--brand-config` for local JSON report branding.
- Added Executive Summary sections to customer-facing report formats.
- Added discovery export enrichment columns for outreach positioning:
  - `pitchAngle`
  - `recommendedOffer`
  - `estimatedNeed`
  - `outreachPriorityReason`

## Verification

Run before publishing:

```bash
npm run release-check
node dist/cli.js --help
node dist/cli.js https://example.com --brand-config brand.json --format pdf --out report.pdf
npm pack
npx --yes --package ./open-local-audit-0.14.0.tgz open-local-audit --help
```

## Notes

- Brand config is local JSON only; the CLI does not fetch remote brand assets or upload report data.
- Brand colors must be six-digit hex values.
- Discovery enrichment remains deterministic local operator guidance and does not send outreach.
