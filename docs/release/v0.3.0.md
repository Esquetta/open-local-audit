# v0.3.0 Release Notes

## Highlights

- Adds standalone HTML report output with `--format html`.
- Expands `--format all` to generate JSON, Markdown, and HTML together.
- Adds batch audits with `--input <path>`.
- Writes batch results into safe per-site output folders.
- Adds tests for HTML rendering, batch input parsing, slugging, and batch report output.

## Verification

Before tagging and publishing:

```bash
npm run release-check
npm pack
npx --yes --package ./open-local-audit-0.3.0.tgz open-local-audit --help
```

After npm publish:

```bash
npm view open-local-audit@0.3.0 version dist.tarball bin
npx --yes open-local-audit@0.3.0 --help
```

## Known limits

- Batch mode runs audits sequentially.
- Batch input files support one URL per line with `#` comments; CSV parsing is still deferred.
- Browser-rendered DOM checks and screenshots are still deferred.
