# Open Local Audit v0.24.0

Release date: 2026-06-03

## Summary

`v0.24.0` adds spreadsheet-ready CSV output to lead shortlist reports. Operators can now rank and suppress leads locally, then review the selected shortlist in Markdown, JSON, or CSV.

## Changes

- Added `shortlist --format csv`.
- Added CSV shortlist columns for rank, company, website, segment, profile, priority, opportunity score, audit score, contact handoff, review context, lead key, and report path.
- Preserved review-state suppression with `--review-csv` before CSV output is rendered.
- Reused CSV formula hardening for shortlist cells before spreadsheet review.

## Example

```bash
open-local-audit shortlist --input leads.csv --out shortlist.csv --format csv
open-local-audit shortlist --input leads.csv --review-csv review.csv --out shortlist.csv --format csv
```

## Verification

Run before publishing:

npm run release-check
npm pack
npx --yes --package ./open-local-audit-0.24.0.tgz open-local-audit --help

## Known limits

- CSV shortlist output writes a local file only.
- CSV shortlist output does not import, send outreach, mutate review CSV files, or sync CRM records.
