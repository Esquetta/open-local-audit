# v0.5.0 Release Notes

## Highlights

- Adds opt-in Playwright-rendered audits with `--render` for sites where static HTML misses client-rendered content.
- Adds batch triage controls for `--segment`, `--min-score`, `--top`, and `--sort score-asc|severity-desc`.
- Adds trust and conversion checks for current date signals, review cues, service detail depth, brand icons, and placeholder social profile links.

## Verification

Before tagging and publishing:

```bash
npm run release-check
npm pack
npx --yes --package ./open-local-audit-0.5.0.tgz open-local-audit --help
```

After npm publish:

```bash
npm view open-local-audit@0.5.0 version dist.tarball bin
npx --yes open-local-audit --help
```

## Known limits

- `--render` requires Playwright to be installed in the calling project and a working browser runtime.
- Static HTML auditing remains the default path for speed and predictable dependency weight.
- Batch triage options apply to the aggregate batch index, not individual per-site report contents.
- Batch input requires `--out-dir` and cannot be combined with a positional URL.
- Batch mode still runs sequentially.
- Screenshots, PDF exports, and a web UI are still deferred.
