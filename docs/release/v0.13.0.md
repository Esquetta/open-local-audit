# v0.13.0 Release Notes

## Highlights

- Added `--lighthouse` for opt-in Lighthouse category scoring.
- Added `--format pdf` for branded single-site PDF reports.
- Added `opportunityReasons` to discovery CSV exports so operators can explain lead scoring.
- Added Lighthouse sections to JSON, Markdown, HTML, and PDF reports.

## Verification

Run before publishing:

```bash
npm run release-check
node dist/cli.js --help
node dist/cli.js https://example.com --format pdf --out report.pdf
npm pack
npx --yes --package ./open-local-audit-0.13.0.tgz open-local-audit --help
```

## Notes

- `--lighthouse` requires a local Chrome or Chromium runtime that Lighthouse can launch.
- `--format pdf` is supported for single URL audits and requires `--out` or `--out-dir`.
- `--format all` continues to write JSON, Markdown, and HTML reports.
