# v0.1.1 Release Notes

## Highlights

- Adds discovery checks for `robots.txt` and `sitemap.xml`.
- Adds Open Graph metadata checks for `og:title`, `og:description`, and `og:url`.
- Reports invalid JSON-LD separately from missing LocalBusiness schema.
- Adds `--format all --out-dir <path>` to write JSON and Markdown reports in one run.
- Expands tests with HTML fixtures and output writer coverage.
- Adds `npm run release-check` and uses it in CI.

## Verification

Before tagging and publishing:

```bash
npm run release-check
npm pack
npx --yes --package ./open-local-audit-0.1.1.tgz open-local-audit --help
```

After npm publish:

```bash
npm view open-local-audit@0.1.1 version dist.tarball bin
npx --yes open-local-audit@0.1.1 --help
```

## Known limits

- The CLI still scans one URL at a time.
- Browser-rendered DOM checks are not implemented yet.
- Broken internal link crawling and screenshot capture are still deferred.
