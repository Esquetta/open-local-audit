# Open Local Audit v0.31.0

Release date: 2026-06-11

## Summary

`v0.31.0` adds website-required filtering to local shortlist reports. Operators can keep shortlist output focused on leads that already have a website while preserving review suppression, filters, sorting, summary JSON, and report formats.

## Changes

- Added `shortlist --require-website`.
- Filtered rows with empty website values after review-state suppression and before sorting and top-N selection.
- Kept Markdown, JSON, CSV, and summary JSON output on the same filtered result set.

## Example

```bash
open-local-audit shortlist --input leads.csv --require-website --out shortlist.json --format json
```

## Verification

```bash
npm run release-check
npm pack
npx --yes --package ./open-local-audit-0.31.0.tgz open-local-audit shortlist --help
```

## Known limits

- Website-required filtering treats empty normalized website values as missing.
- Filtering does not mutate source files, mutate review CSV files, call APIs, send outreach, or sync CRM records.
