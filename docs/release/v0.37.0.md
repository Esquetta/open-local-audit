# Open Local Audit v0.37.0

Release date: 2026-06-17

## Summary

`v0.37.0` adds missing-website filtering to local shortlist reports. Operators can build a website-enrichment backlog from leads without a website while preserving review suppression, filters, sorting, summary JSON, and report formats.

## Changes

- Added `shortlist --missing-website`.
- Filtered rows with empty website values after review-state suppression and before sorting and top-N selection.
- Kept Markdown, JSON, CSV, and summary JSON output on the same filtered result set.

## Example

```bash
open-local-audit shortlist --input leads.csv --missing-website --out shortlist.json --format json
```

## Verification

```bash
npm run release-check
npm pack
npx --yes --package ./open-local-audit-0.37.0.tgz open-local-audit shortlist --help
```

## Known limits

- Missing-website filtering treats an empty website value as missing website readiness.
- Filtering does not mutate source files, mutate review CSV files, call APIs, send outreach, or sync CRM records.
