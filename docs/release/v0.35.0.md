# Open Local Audit v0.35.0

Release date: 2026-06-15

## Summary

`v0.35.0` adds missing-report filtering to local shortlist reports. Operators can build a report backlog from leads that do not yet have report paths while preserving review suppression, filters, sorting, summary JSON, and report formats.

## Changes

- Added `shortlist --missing-report`.
- Filtered rows with empty `reportPath` values after review-state suppression and before sorting and top-N selection.
- Kept Markdown, JSON, CSV, and summary JSON output on the same filtered result set.

## Example

```bash
open-local-audit shortlist --input leads.csv --missing-report --out shortlist.json --format json
```

## Verification

```bash
npm run release-check
npm pack
npx --yes --package ./open-local-audit-0.35.0.tgz open-local-audit shortlist --help
```

## Known limits

- Missing-report filtering treats an empty `reportPath` as missing local report readiness.
- Filtering does not mutate source files, mutate review CSV files, call APIs, send outreach, or sync CRM records.
