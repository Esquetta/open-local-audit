# Open Local Audit v0.20.0

Release date: 2026-05-27

## Summary

`v0.20.0` adds a local CRM import quality gate for CSV files generated with the CRM export preset. Operators can validate a file before importing it into external tools without calling any CRM API or sending outreach.

## Changes

- Added `validate-export --input <path> --preset crm`.
- Added Markdown validation output by default.
- Added JSON validation output with `--format json`.
- Reported row counts, error counts, warning counts, and issue details.
- Checked for missing CRM columns, missing `companyName`, missing `website`, missing `leadKey`, duplicate `leadKey` values, low or empty contact confidence, and manual-review contact handoffs.

## Example

```bash
open-local-audit validate-export --input crm-leads.csv --preset crm
open-local-audit validate-export --input crm-leads.csv --preset crm --format json
```

## Verification

Run before publishing:

```bash
npm run release-check
npm pack
npx --yes --package ./open-local-audit-0.20.0.tgz open-local-audit --help
```

## Known limits

- Validation is local CSV inspection only.
- Validation does not create, update, or sync CRM records.
- Validation does not send outreach.
- Only the `crm` export preset is supported by `validate-export` in this release.
