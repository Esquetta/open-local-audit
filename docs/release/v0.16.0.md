# Open Local Audit v0.16.0

Release date: 2026-05-20

## Summary

`v0.16.0` adds advisory outreach handoff guidance to discovery CSV exports. Operators can now see the preferred manual contact channel, the suggested next action, and the reason behind that handoff without the CLI sending outreach or changing provider boundaries.

## Changes

- Added `preferredContactChannel`, `outreachAction`, and `contactabilityReason` to discovery CSV exports.
- Added deterministic channel selection from audited public website contact fields: email, WhatsApp, phone, contact page, then manual review.
- Added dry-run and no-contact handoff guidance that does not invent contact data.
- Preserved CSV formula hardening for all new handoff fields.
