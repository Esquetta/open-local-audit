# Open Local Audit v0.30.0

Release date: 2026-06-09

## Summary

`v0.30.0` adds review-status exclusion to local shortlist reports. Operators can remove active statuses such as deferred leads from a shortlist while keeping review suppression, filters, sorting, summary JSON, and report formats intact.

## Changes

- Added `shortlist --exclude-review-status <status>`.
- Matched excluded review status values with case-insensitive exact comparison.
- Applied exclusion after review-state suppression and before sorting and top-N selection.
- Kept Markdown, JSON, CSV, and summary JSON output on the same filtered result set.

## Example

```bash
open-local-audit shortlist --input leads.csv --exclude-review-status deferred --out shortlist.json --format json
```

## Verification

```bash
npm run release-check
npm pack
npx --yes --package ./open-local-audit-0.30.0.tgz open-local-audit shortlist --help
```

## Known limits

- Review-status exclusion uses exact normalized values, not partial or fuzzy matching.
- Exclusion does not mutate source files, mutate review CSV files, call APIs, send outreach, or sync CRM records.
