# Open Local Audit v0.19.0

Release date: 2026-05-26

## Summary

`v0.19.0` adds a CRM-ready local CSV export preset for batch and discovery workflows. Operators can generate normalized import files while keeping the default operator CSV unchanged and without syncing to any CRM API.

## Changes

- Added `--export-preset standard|crm` for batch and discovery CSV exports.
- Added CRM-ready columns for company identity, website, segment, profile, scoring, contact handoff, source, lead key, and report path.
- Preserved the standard CSV export shape as the default.
- Kept CSV formula hardening active for CRM preset cells.
- Kept CRM export local-only: no CRM sync, no remote API calls, and no outreach sending.
