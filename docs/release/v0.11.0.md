# Open Local Audit v0.11.0

## Highlights

- Added `--limit` to control Google Places candidate volume, with a documented cap.
- Added `--max-audits` to limit website audits while preserving all discovered leads in `leads.csv`.
- Added `--summary-json` and terminal summary output for discovery runs.
- Added `opportunityScore` to prospect CSV exports for local operator triage.
- Hardened CSV exports against formula-like spreadsheet cells.
- Added a Google Maps Platform billing warning when `--provider google-places` is used.

## Verification

Run before tagging and publishing:

```bash
npm run release-check
npm pack
npx --yes --package ./open-local-audit-0.11.0.tgz open-local-audit discover --help
```

Run after publishing:

```bash
npm view open-local-audit@0.11.0 version dist.tarball bin
npx --yes open-local-audit@0.11.0 discover --help
```

## Known Limits

- `--limit` controls one Google Places Text Search request; pagination is not implemented.
- `--max-audits` caps audit execution only; unaudited website-present leads remain in the CSV output.
- `google-places` requires `GOOGLE_MAPS_API_KEY`, and usage can incur Google Maps Platform billing.
- CI tests use mocked Google responses only.
- The provider does not scrape Google Maps, collect reviews/photos/ratings, send outreach, or store raw Places responses.
