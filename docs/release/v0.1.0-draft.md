# v0.1.0 Draft Release Notes

## Status

Draft only. Do not create a GitHub release or publish to npm until the release readiness checklist is fully complete.

## Highlights

- Adds the first TypeScript CLI scaffold for auditing one public URL.
- Produces JSON and Markdown audit reports.
- Includes an initial rule set for website basics, local contact readiness, structured data, map links, and image alt coverage.
- Adds Vitest coverage for rule behavior and report rendering.
- Adds example report artifacts for release review.

## Verification target

Before tagging this release:

```bash
npm test
npm run lint
npm run build
npm pack --dry-run
```

Also verify install from the generated tarball and run the CLI through `npx`.

## Known limits

- The CLI scans one URL at a time.
- Browser-rendered DOM checks are not implemented yet.
- `robots.txt`, `sitemap.xml`, broken-link, and screenshot checks are deferred.
