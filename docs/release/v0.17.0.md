# Open Local Audit v0.17.0

Release date: 2026-05-22

## Summary

`v0.17.0` adds advisory fuzzy duplicate lead review to discovery duplicate reporting. Operators can review likely duplicate businesses across reruns using local JSON output while keeping suppression, outreach, and CRM decisions fully manual.

## Changes

- Added `fuzzyDuplicateGroups` to discovery duplicate JSON output.
- Added duplicate review reasons for likely business-label and website-domain similarity.
- Preserved exact stable lead-key duplicate reporting in `duplicateGroups`.
- Kept fuzzy matching advisory only: no automatic suppression, no review-status changes, no outreach sending, and no CRM sync.
