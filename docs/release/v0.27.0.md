# Open Local Audit v0.27.0

Release date: 2026-06-06

## Summary

`v0.27.0` adds review-status filtering to local shortlist reports. Operators can focus active review queues, such as pending leads, after completed or suppressed review rows have already been removed.

## Changes

- Added `shortlist --review-status <status>`.
- Matched review status values with case-insensitive exact comparison.
- Applied review-status filtering after review-state suppression and before ranking and top-N selection.
- Kept Markdown, JSON, and CSV shortlist output on the same filtered result set.

## Example

```bash
open-local-audit shortlist --input leads.csv --review-csv review.csv --review-status pending --out shortlist.json --format json
```

## Verification

```bash
npm run release-check
npm pack
npx --yes --package ./open-local-audit-0.27.0.tgz open-local-audit --help
```

## Known limits

- Review-status filters use exact normalized values, not partial or fuzzy matching.
- Filtering does not mutate source files, mutate review CSV files, call APIs, send outreach, or sync CRM records.
