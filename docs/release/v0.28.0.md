# Open Local Audit v0.28.0

Release date: 2026-06-07

## Summary

`v0.28.0` adds sort modes to local shortlist reports. Operators can rank selected leads by opportunity, audit score, company name, or oldest review date before top-N selection.

## Changes

- Added `shortlist --sort <sort>`.
- Supported `opportunity-desc`, `score-desc`, `company-asc`, and `last-reviewed-asc`.
- Kept filtering and review suppression ahead of sorting and top-N selection.
- Kept Markdown, JSON, and CSV shortlist output on the same sorted result set.

## Example

```bash
open-local-audit shortlist --input leads.csv --sort score-desc --out shortlist.json --format json
```

## Verification

```bash
npm run release-check
npm pack
npx --yes --package ./open-local-audit-0.28.0.tgz open-local-audit shortlist --help
```

## Known limits

- Sort modes are fixed to the documented values.
- Sorting does not mutate source files, mutate review CSV files, call APIs, send outreach, or sync CRM records.
