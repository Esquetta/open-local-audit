# Open Local Audit v0.21.0

Release date: 2026-05-28

## Summary

`v0.21.0` adds local report packaging for existing single-site report folders. Operators can turn generated report artifacts into a small customer-shareable folder without uploading data, sending outreach, or syncing to a CRM.

## Changes

- Added `package-report --input <path> --out <path>`.
- Generated a package `README.md` with score, included files, and top findings.
- Generated `next-actions.md` with a recommended fix order and contact readiness summary.
- Generated `manifest.json` for package metadata.
- Copied available JSON, Markdown, HTML, and PDF report artifacts into `reports/`.

## Example

```bash
open-local-audit package-report --input reports/example-com --out packages/example-com
```

## Verification

Run before publishing:

```bash
npm run release-check
npm pack
npx --yes --package ./open-local-audit-0.21.0.tgz open-local-audit --help
```

## Known limits

- Packaging reads an existing single-site report directory only.
- Packaging requires `open-local-audit-report.json` in the input directory.
- Packaging does not upload reports, send outreach, or sync CRM records.
- ZIP archive generation is not included in this release.
