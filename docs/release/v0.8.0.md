# Open Local Audit v0.8.0

## Highlights

- Added `--concurrency <count>` for controlled parallel batch audits.
- Added batch index insights: average score, profile breakdown, segment breakdown, and frequent findings.
- Added real profile-specific findings for dental, beauty, restaurant, and contractor audits.
- Kept batch result order stable while allowing multiple audits to run in flight.

## Verification

Run before tagging and publishing:

```bash
npm run release-check
npm pack
npx --yes --package ./open-local-audit-0.8.0.tgz open-local-audit --help
```

Run after publishing:

```bash
npm view open-local-audit@0.8.0 version dist.tarball bin
npx --yes open-local-audit --help
```

## Known Limits

- `--concurrency` controls audit execution only; report writing still uses per-site output folders.
- Higher concurrency can create more network load against audited public sites, so conservative values are recommended.
- Profile-specific findings are deterministic heuristics and may need human review for edge-case businesses.
- Web UI, branded PDF reports, Lighthouse integration, and broader profile packs remain deferred.
