# Open Local Audit v0.23.0

Release date: 2026-06-01

## Summary

`v0.23.0` adds local review-state handling to lead shortlist reports. Operators can reuse a review CSV to skip already handled leads while keeping active review context visible in the shortlist.

## Changes

- Added `shortlist --review-csv <path>`.
- Suppressed leads marked `rejected`, `contacted`, `not-fit`, `not_a_fit`, `do-not-contact`, or `suppressed`.
- Matched review rows by `leadKey`, normalized website, or company label.
- Added `reviewStatus`, `reviewReason`, and `lastReviewedAt` context to Markdown and JSON shortlist output.
- Reported suppressed row counts in CLI output and Markdown summaries.

## Example

```bash
open-local-audit shortlist --input leads.csv --review-csv review.csv --out shortlist.md
open-local-audit shortlist --input crm-leads.csv --review-csv review.csv --out shortlist.json --format json
```

## Verification

Run before publishing:

```bash
npm run release-check
npm pack
npx --yes --package ./open-local-audit-0.23.0.tgz open-local-audit --help
```

## Known limits

- Review CSV handling reads local files only.
- Review CSV handling does not mutate the source review file.
- Shortlist generation does not call APIs, send outreach, or sync CRM records.
