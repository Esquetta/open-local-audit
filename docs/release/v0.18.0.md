# Open Local Audit v0.18.0

Release date: 2026-05-23

## Summary

`v0.18.0` adds batch contact and outreach rollups to aggregate batch indexes. Operators can review public contact coverage, confidence, and preferred manual contact channels across a batch without sending outreach or syncing to external systems.

## Changes

- Added public contact coverage rollups to JSON, Markdown, and HTML batch indexes.
- Added preferred manual outreach channel rollups to batch indexes.
- Added successful-entry contact and outreach metadata to batch index JSON.
- Added `contactConfidence`, `preferredContactChannel`, and `contactabilityReason` columns to batch prospect CSV exports.
- Kept failed batch entries from inventing contact or outreach metadata.
