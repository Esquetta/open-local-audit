# Open Local Audit v0.15.0

Release date: 2026-05-19

## Summary

`v0.15.0` adds website-derived public contact enrichment. Audited pages now expose Contact Readiness in reports, and discovery CSV exports can carry public contact channels for manual operator triage.

## Changes

- Added public contact extraction for email, phone, WhatsApp, contact-page, and social-profile signals found in audited website HTML.
- Added Contact Readiness sections to Markdown, HTML, and PDF reports.
- Added discovery CSV columns for `publicEmail`, `publicPhone`, `whatsappUrl`, `contactPageUrl`, `socialProfiles`, `contactConfidence`, and `contactSource`.
- Kept Google Places enrichment boundaries unchanged: Places still supplies only place ID, display name, and website URI.
- Preserved CSV formula hardening for the new contact columns.
