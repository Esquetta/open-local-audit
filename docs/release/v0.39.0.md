# Open Local Audit v0.39.0

Release date: 2026-06-20

## Summary

`v0.39.0` adds reviewed-before filtering to local shortlist reports. Operators can build a re-review queue from active leads whose valid review timestamps are strictly earlier than an explicit calendar threshold.

## Changes

- Added `shortlist --reviewed-before <date>`.
- Added strict `YYYY-MM-DD` threshold validation and UTC boundary comparisons.
- Excluded equal, blank, invalid, and zone-less review timestamps from the filtered result.
- Kept Markdown, JSON, CSV, and summary JSON output on the same filtered result set.

## Example

```bash
open-local-audit shortlist --input leads.csv --reviewed-before 2026-06-20 --out shortlist.json --format json
```

## Verification

```bash
npm run release-check
npm pack
npx --yes --package ./open-local-audit-0.39.0.tgz open-local-audit shortlist --help
```

## Known limits

- The threshold must be an explicit valid `YYYY-MM-DD` value; the command does not infer a default or calculate relative review age.
- Blank, invalid, and zone-less row timestamps are excluded rather than interpreted in the local timezone.
- Filtering does not mutate source files, mutate review CSV files, call APIs, send outreach, or sync CRM records.
