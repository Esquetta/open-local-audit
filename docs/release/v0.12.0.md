# Open Local Audit v0.12.0

## Highlights

- Added `--review-csv` for preserving local operator review decisions across discovery reruns.
- Added `--duplicates-json` for exact stable lead-key duplicate reports.
- Expanded industry profiles with lawyer, clinic, gym, hotel, and auto-service heuristics.
- Polished standalone HTML reports with branded layout, summary cards, and clearer priority sections.
- Kept suppression and review decisions local; no outreach sending or remote CRM sync is included.

## Verification

Run before tagging and publishing:

```bash
npm run release-check
npm pack
npx --yes --package ./open-local-audit-0.12.0.tgz open-local-audit discover --help
```

Run after publishing:

```bash
npm view open-local-audit@0.12.0 version dist.tarball bin
npx --yes open-local-audit@0.12.0 discover --help
```

## Known Limits

- `--review-csv` is local operator state only and does not send outreach or sync to a CRM.
- `--duplicates-json` groups exact stable lead-key matches; it does not perform fuzzy business-name matching.
- Industry profiles are deterministic heuristics and still require human review before outreach or sales decisions.
- `google-places` requires `GOOGLE_MAPS_API_KEY`, and usage can incur Google Maps Platform billing.
