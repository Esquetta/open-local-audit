# v0.6.0 Release Notes

## Highlights

- Adds `--screenshot` to capture rendered homepage screenshots as visual evidence.
- Adds `visualEvidence` metadata to JSON reports.
- Adds Visual Evidence sections to Markdown and HTML reports.
- Adds batch-aware screenshot paths under each per-site report directory.

## Verification

Before tagging and publishing:

```bash
npm run release-check
npm pack
npx --yes --package ./open-local-audit-0.6.0.tgz open-local-audit --help
```

After npm publish:

```bash
npm view open-local-audit@0.6.0 version dist.tarball bin
npx --yes open-local-audit --help
```

## Known limits

- `--screenshot` requires `--out-dir` so report links can reference local artifact paths.
- `--screenshot` uses Playwright and requires Playwright to be installed in the calling project.
- Static HTML auditing remains the default path when `--render` and `--screenshot` are not used.
- Batch mode still runs sequentially.
- PDF exports and a web UI are still deferred.
