# Open Local Audit v0.7.0

## Highlights

- Added industry profiles: `generic`, `dental`, `beauty`, `restaurant`, and `contractor`.
- Added `--profile <profile>` for single URL and batch audits.
- Added optional `profile` CSV input column for per-site batch profile overrides.
- Added profile metadata to JSON, Markdown, HTML, and batch index outputs.
- Added `--export-csv <path>` for batch prospect exports with URL, label, segment, profile, status, score, top finding, report path, and error columns.

## Verification

Run before tagging and publishing:

```bash
npm run release-check
npm pack
npx --yes --package ./open-local-audit-0.7.0.tgz open-local-audit --help
```

Run after publishing:

```bash
npm view open-local-audit@0.7.0 version dist.tarball bin
npx --yes open-local-audit --help
```

## Known Limits

- Profile adjustments are deterministic severity and recommendation adjustments, not full separate rule sets.
- `--export-csv` is batch-only.
- Batch audits still run sequentially.
- Web UI, branded PDF reports, and deeper profile-specific rule packs remain deferred.
