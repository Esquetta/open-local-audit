# Open Local Audit v0.9.0

## Highlights

- Added `discover --input places.csv --provider manual-csv` for local lead discovery from operator-prepared CSV files.
- Added `leads.csv` output with `hasWebsite`, `websiteUrl`, `auditStatus`, `priority`, `nextAction`, `reportPath`, and `error` columns.
- Reused the existing batch audit pipeline for website-present candidates.
- Added `--dry-run` for CSV-only triage without auditing websites.
- Kept the discovery boundary explicit: Google Maps scraping, `google-places` provider calls, and outreach sending are not supported.

## Verification

Run before tagging and publishing:

```bash
npm run release-check
npm pack
npx --yes --package ./open-local-audit-0.9.0.tgz open-local-audit --help
```

Run after publishing:

```bash
npm view open-local-audit@0.9.0 version dist.tarball bin
npx --yes open-local-audit --help
```

## Known Limits

- Discovery supports `manual-csv` only in this release.
- Google Places is deferred until an official API-based provider is approved.
- Discovery does not send outreach or collect Google review/photo data.
- Web UI, branded PDF reports, Lighthouse integration, and broader profile packs remain deferred.
