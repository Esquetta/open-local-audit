# Open Local Audit v0.25.0

Release date: 2026-06-04

## Summary

`v0.25.0` adds opportunity-score filtering to local shortlist reports. Operators can keep shortlist output focused on higher-value leads while preserving review-state suppression and Markdown, JSON, or CSV output.

## Changes

- Added `shortlist --min-opportunity-score <score>`.
- Filtered low-opportunity leads after `--review-csv` suppression and before `--top` ranking.
- Added filtered row counts to CLI output, Markdown summaries, and JSON results.
- Kept CSV, Markdown, and JSON shortlist output on the same filtered result set.

## Example

```bash
open-local-audit shortlist --input leads.csv --min-opportunity-score 80 --out shortlist.md
open-local-audit shortlist --input leads.csv --review-csv review.csv --min-opportunity-score 80 --out shortlist.csv --format csv
```

## Verification

Run before publishing:

```bash
npm run release-check
npm pack
npx --yes --package ./open-local-audit-0.25.0.tgz open-local-audit --help
```

## Known limits

- Opportunity-score filtering affects local shortlist output only.
- Filtering does not mutate source lead files, send outreach, mutate review CSV files, or sync CRM records.
