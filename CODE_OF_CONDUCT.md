# Code of Conduct

Open Local Audit uses a simple maintainer-enforced conduct policy for project spaces.

## Expected behavior

- Be direct, respectful, and evidence-focused.
- Keep discussion tied to the project and its users.
- Give reproducible examples when reporting problems.
- Assume public issue threads may be read by business owners, developers, and maintainers.

## Unacceptable behavior

- Harassment, threats, personal attacks, or discriminatory language.
- Spam, automated lead generation, or scraping requests that conflict with the project ethics policy.
- Sharing private customer, prospect, or security-sensitive data in public threads.

## Enforcement

Maintainers may edit, hide, or remove comments; close issues; block users; or limit participation when behavior harms project work or user safety.

Security issues should follow [SECURITY.md](./SECURITY.md), not public issue threads.
